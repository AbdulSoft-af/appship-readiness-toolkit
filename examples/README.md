# Sample Android scanner fixture

`sample_android_project/` is an intentionally incomplete native Android source fixture for learning how AppShip reports release-readiness findings. Its Gradle wrapper is deliberately a stub that exits with an error; the fixture is not a functioning application and is not intended to build or publish.

Open the folder with **Scan project folder** or download the separate `AppShip_Sample_Android_Project_v2.zip` delivered alongside the toolkit package.
